# Naman Nagar — Developer Portfolio

A clean and responsive personal portfolio website built to showcase my
skills, projects, and development journey.

## About the Project

This portfolio represents me as a Full Stack / MERN Stack Developer.

The website focuses on keeping things simple, readable, and user-friendly
instead of adding unnecessary sections or animations.

## Features

- Responsive design
- Mobile-friendly navigation
- Hamburger menu for small screens
- Typing text animation
- Scroll reveal animations
- Active navigation based on current section
- Smooth scrolling
- Project showcase
- Email contact option
- GitHub links
- Font Awesome icons
- SEO-friendly meta information
